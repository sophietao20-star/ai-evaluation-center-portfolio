Overview

用 100 个正式 Case、每个模型 148 次执行，评估 OpenMAIC 课程大纲生成在真实产品约束下是否既能被系统直接消费，又具有稳定的教学可用性。

What This Benchmark Measures

候选模型根据课程主题、材料、图片、受众和结构约束生成可供 OpenMAIC 继续生产课程的 Outline。评测同时检查 JSON/Shape 可用性、常规教学质量、受众适配、来源忠实、视觉理解、长结构稳定性和多语言组合任务。

Dataset Design

  • 100 个逻辑 Case，覆盖常规生成、来源忠实、视觉理解、长 Schema、JSON 压力、受众适配、多语言与组合约束。
  • 高风险 Case 重复执行，因此每个模型共 148 次调用；重复 Case 按最差一次聚合，暴露生产稳定性风险。
  • 所有模型使用同一冻结 Dataset v1.1、Rubric v1.1 和 Comparison Group。

Methodology

  1. 01通过真实 Outline generation core 执行同一组固定输入。
  2. 02机器层检查请求、JSON 解析、Shape 与必要字段；不可消费结果不能被内容分掩盖。
  3. 03GPT-5.6 Sol 按 pass / minor / major / fail 审阅，并将标签映射为 1 / 0.75 / 0.25 / 0。
  4. 04先计算七个维度分，再按冻结权重得到 Content Score；Token 和延时只作效率参考。

Core Metrics

维度权重检查内容
JSON / Shape20%解析、必需字段、系统可消费结构
常规教学质量20%课程结构、具体性、教学价值
受众适配10%语言、难度、活动与目标学习者匹配
来源忠实度15%不编造材料外事实并诚实处理边界
视觉理解15%图表、图片、数字和趋势读取
长结构稳定性10%长输出完整性、Schema 一致性
多语言 / 组合10%目标语言和多约束同时满足

Key Insights

  • Gemini 3.6 Flash、Qwen3.8-27B 与 Qwen3.8 Max 的 Content Score 接近，差异主要来自不同能力维度，而非单一总分。
  • 来源忠实与视觉理解仍是多数模型的共同短板，不能只看常规教学质量。
  • 部分模型执行层失败率较高，因此质量得分必须与失败率和运行效率一起阅读。

Known Limitations

  • 当前仍为 Pilot，Judge 结论经过重点争议样本复核，但尚未完成人类多评审者一致性研究。
  • Content Score 不包含成本和延时；不同网关和 Thinking 配置的运行指标只作方向性参考。
  • Dataset 主要验证 Outline generation，不代表 Slide 渲染、课堂互动或完整课程 Journey。
