Overview

What This Benchmark Measures

候选模型接收一份单页 Design Brief，其中包含必须呈现的内容、布局要求，以及可选的指定图片。本 Bench 同时检查模型是否完整、准确地执行 Brief，以及真实渲染后的页面是否清晰、可读并具备演示完成度；不评估大纲、跨页连贯性、讲稿与动作、动画、媒体生成质量或课堂互动。

Dataset Design

  • 120 个固定单页任务，覆盖教育、商业、产品与工程场景。
  • 页面类型包括表格、图表、公式、流程、KPI、信息密集页与媒体占位；其中 18 题要求使用指定源图片。
  • Dataset 以人工编写的 production-like Brief 为主，不是生产流量随机抽样；不含 PDF 输入，语言以中文为主。

Methodology

  1. 01候选模型根据 Brief 和指定素材生成 Slide JSON。
  2. 02Harness 解析输出，并校验基础 Slide Schema。
  3. 03当前 OpenMAIC Renderer 将合法 JSON 真实渲染为 16:9 页面截图。
  4. 04GPT-5.6 Sol 同时读取 Brief、Slide JSON 和截图，使用统一 Rubric 分别评估 Fidelity 与 Layout。
  5. 05所有模型使用相同的 Dataset、Rubric、Renderer 和 Judge；执行失败保留在数据质量统计中，不虚构质量分。

Core Metrics

指标检查内容高分表示
Fidelity必需文字、内容完整性、信息编造、语言一致性、指定素材使用准确、完整地执行 Brief
Layout层级、间距、重叠与越界、可读性、空间利用、图表与素材编排、视觉完成度渲染页面真正适合演示展示
Overall Quality综合 Fidelity 与 Layout内容准确性与视觉质量较均衡
Execution Success Rate120 个任务中完成生成并进入评分的比例模型与运行链路表现稳定

Fidelity 与 Layout 均由 0–5 Judge 分换算到 0–100；质量均分只使用成功且有有效 Judge 分的 Case。

Key Insights

  • Layout 是当前最普遍的短板：六个模型中有五个的 Fidelity 明显高于 Layout。
  • OpenMAIC 27B Slide RL v2 已接近头部模型，当前差距主要来自 Layout。
  • Qwen 3.7 Plus 同样呈现内容与布局能力分离：内容保真明显高于页面布局。

Known Limitations

  • 当前仍为 Pilot，尚未完成正式的人类评分一致性研究，也没有置信区间。
  • 不同模型存在少量执行失败，因此质量均分的有效 Case 数并不完全相同。
  • Dataset 为人工编写的单页任务，中文占 88.3%；不覆盖 PDF、跨页、媒体生成或互动能力。
  • 不同网关上的 Token 与延时只能作为方向性参考，不能视为严格的成本或性能对比。
